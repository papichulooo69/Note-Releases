### ⚠️ Hinweis zum ersten Start (macOS Gatekeeper)

Da **Note** aktuell noch nicht über ein Apple-Developer-Zertifikat notariell beglaubigt ist, blockiert macOS beim ersten Öffnen ggf. den Start:

1. **Note.app** in den Ordner **Programme** ziehen und einmal öffnen.
2. Falls die Meldung erscheint, dass Apple die App nicht überprüfen kann: **Systemeinstellungen** → **Datenschutz & Sicherheit** öffnen, nach unten scrollen und auf **Dennoch öffnen** klicken *(ggf. Passwort oder Touch ID bestätigen)*.

---

### ⚠️ First Launch Note (macOS Gatekeeper)

Because **Note** is currently distributed without Apple notarization, macOS may block the first launch:

1. Drag **Note.app** into the **Applications** folder and try opening it once.
2. If macOS says the app cannot be verified: open **System Settings** → **Privacy & Security**, scroll down, and click **Open Anyway** *(confirm with password or Touch ID if prompted)*.
